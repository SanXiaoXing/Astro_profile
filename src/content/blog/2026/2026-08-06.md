## 前言

最近一段时间，我一直在思考一个问题：

为什么以前喜欢写代码、喜欢折腾技术的自己，好像慢慢变得没有那么快乐了？

直到最近的一次经历，我才发现，也许不是我不喜欢软件开发了，而是我很久没有真正做一个属于自己的东西。

于是我和 ChatGPT 进行了一次对话，尝试重新梳理这段时间的变化。

> [!quote] 
>  我开始思考：
>  为什么以前喜欢写代码、喜欢折腾技术的自己，好像慢慢没有那么快乐了？ 
>  是我不喜欢软件开发了，还是我失去了创造的空间？

## 与 ChatGPT 的一次对话

:::chat{role="assistant"}
我读了你最近的一些记录，发现一个明显的变化：

以前你的生活状态更多是在“完成任务”，而最近你开始主动创造一些属于自己的东西，比如 SnapClaim、博客、各种技术实验。

是什么事情让你意识到，自己已经很久没有真正为自己做事情了？
:::

:::chat{role="user"}
我觉得可能是之前在出差的时候让我想了很多。

客户要求的加班，领导“视察”时候的加班，以及出差空余时候的健身和玩游戏后的感受，让我意识到不能让自己一直荒废下去。

更多的是想学习一些新的技能，让自己变得更健康，让自己的生活产生一些积极的变化。
:::

:::chat{role="assistant"}
你提到了“不想让自己荒废”。

那么你认为“荒废”具体意味着什么？

是技术没有成长？
还是生活只有工作？
还是觉得自己正在失去那个喜欢探索和创造的自己？
:::

:::chat{role="user"}
对于我来说，“荒废”更多的是工作以及生活中遇到的一些没有意义的事情。

我并不是不喜欢忙碌，相反，我喜欢自己忙碌，并且有所作为、有所产出。

真正让我难受的是投入很多时间，但是看不到成长，也不知道这些事情最终有什么意义。
:::

:::chat{role="assistant"}
> [!quote] 真正让我疲惫的，不是忙碌。 
> 而是投入大量时间，却不知道这些事情最终会产生什么价值。

所以你排斥的并不是忙碌，而是一种低价值的消耗。

你喜欢的是有效率、有反馈、有创造性的投入。
:::

:::chat{role="user"}
对我来说，“我不想一直这样下去”的最大原因，是工作中的沟通。

很多事情需求并不明确，软件无法真正开始开发。

很多时候都是东拼西凑出来的需求，很少有人真正了解甲方想要什么，以及这个需求最终应该做成什么样子。
:::

:::chat{role="assistant"}
这和 SnapClaim 形成了一个非常明显的对比。

工作中：

别人定义问题，你负责实现。

而 SnapClaim：

你发现问题，定义需求，设计方案，最终实现产品。

那么是什么时候让你重新感觉到：

“原来我当初选择软件开发，就是为了这个。”
:::

:::chat{role="user"}
其实就是把想法变成一个可用的产品。

最开始 SnapClaim 只是因为长期出差，经常遇到报销流程的问题。

比如临时退票改签，需要额外审批，报销周期变长。

虽然我有记录，但是具体细节经常想不起来，所以想做一个减少整理 Excel 的工具。

最开始是 Python 版本，后来发现效率和体验有限，于是逐渐发展到了 Tauri 2 + Rust，再到现在 Flutter + Rust 的移动版本。

这个过程让我重新感受到，当初为什么学习软件开发。
:::

:::chat{role="assistant"}
我很好奇：

当 SnapClaim 第一次真正运行起来，比如 OCR 成功识别发票，或者一个新功能上线时，你是什么感觉？
:::

:::chat{role="user"}
那种感觉更像：

“哦～OCR 识别成功了。”

“哇，一个新功能能够上线了。”

然后马上想着：

“等会找个人试一下，看看还有没有其他问题。”
:::

:::chat{role="assistant"}
这个回答很有意思。

你关注的不是技术本身，而是一个想法真正进入现实。

你享受的是：

从一个想法开始，到成为一个真实产品，再到有人使用它的过程。
:::

:::chat{role="user"}
我觉得真正让我觉得是在做产品，是别人开始使用它。

比如别人看到我的软件，会好奇问：

“这是什么？”

“能不能给我试一下？”

然后他们反馈一些意见，我进行修改。

甚至加入一些小彩蛋。

当别人认可这个想法的时候，会让我觉得很有成就感。
:::

:::chat{role="assistant"}
你提到“小彩蛋”，其实很能说明你的想法。

因为软件不仅仅是功能集合。

它应该服务于人，同时也应该包含创造者的一些思考和个性。
:::

:::chat{role="user"}
我觉得软件本身就是为人服务的。

更多的是需要一些人的思考在里面。

甚至能够展示出我的一些个性或者小想法。
:::

:::chat{role="assistant"}
那么最后一个问题：

经历这段时间，你觉得自己真正找回的是什么？
:::

:::chat{role="user"}
我觉得自己找回的是自己的生活节奏。

我很喜欢这种有时间处理自己的事务，忙自己想忙的东西。

休闲的时候看一会书，看一部剧，跳半个小时的跳绳。

这些事情都是重新找回自己的方式。
:::

## 总结

回顾这段时间，我发现自己真正想找回的，并不是逃离工作，也不是拒绝忙碌。

相反，我依然喜欢创造，喜欢解决问题，喜欢让一个想法变成现实。

只是我希望自己的时间投入能够产生价值。

SnapClaim 给我的最大意义，不只是完成了一个软件。

它让我重新确认：

我喜欢成为一个创造者。

软件不仅是代码和功能，它也是人与人之间产生连接的一种方式。

而生活，也不应该只有完成任务。

> [!quote] 小结
>
> 我找回的不是某一个技术方向，
> 而是属于自己的生活节奏。
> 有时间创造，有时间学习，也有时间享受生活。
> 这才是我最近重新找回的东西。
