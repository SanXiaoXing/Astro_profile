# 原由

:::note{title="原由"}

- 由于最近需要查看一些 pyqt5 的界面，不得不将 pycharm 进行安装外部插件
- 但是，我是用的是 Anaconda，包含多个 python 环境，这就导致了多环境的 pyqt 很混乱。
:::

网上配置的 Pyqt 的环境都是基于单一 python 环境进行配置，且并没有根据当前环境进行适配配置，对此我想发表一下我的个人间接。

# 创建外部工具


:::warning{title="注意"}

由于 2025 年 pycharm 就开始对大众免费开放使用，并且适配中文，此下内容均以中文进行内容讲解
:::

创建外部工具都是在 `设置 - 工具 - 外部工具`

## QtDesigner

这是打开 PyqtDesigner 界面内容的配置。

:::warning{title="叠甲保护"}

于在 Anaconda 中会有多个环境配置，且每次切换环境不一定有 pyqt tools 的安装下载，需要确保此环境中包含对应的 python 库

:::

1. 添加外部工具
2. **名称命名**为 `QtDesigner`
3. **程序**填写 `$PyInterpreterDirectory$\Library\bin\designer.exe`
4. **实参** : `$FilePath$`
5. **工作目录** : `$FileDir$`
6. **高级选项**勾选 **执行后同步文件**，**打开工具输出控制台**

此时右键 ui，找到外部工具即可打开对应的 ui 界面并编辑界面

:::info{title="提示"}

在新版本的Anaconda中，pyqt5的QtDesigner并不在`\Library\bin\`下，可检查对应的路径进行查看是否安装成功。

检查常见的安装位置：
```bash
envs\pro3810\Lib\site-packages\qt5_applications\Qt\bin\designer.exe
envs\pro3810\Library\bin\designer.exe
envs\pro3810\Scripts\pyqt5-tools.exe
```

:::

## PyUIC

编译 UI 文件

1. 添加外部工具
2. **名称**: PyUIC
3. **程序** : `$PyInterpreterDirectory$\Scripts\pyuic5.exe`
4. **实参** : `$FileName$ -o Ui_$FileNameWithoutExtension$.py`
5. **工作目录**: `$FileDir$`


:::info{title="提示"}

实参中文件名称可根据项目需求进行个性化配置，此处编译的 python 文件名称为 Ui_name，可进行自定义的更改

:::
