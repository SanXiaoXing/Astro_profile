# 欢迎来到 Astro Profile Docs

这里是基于 Astro 框架构建的个人博客项目的技术文档库。

## 项目简介

本博客项目 (`SanXiaoXing/Astro_profile`) 采用 **Astro** 框架开发，结合了现代化前端技术栈，旨在提供一个极速、美观且功能丰富的个人展示与知识沉淀平台。

### 核心特性

- ⚡️ **极速加载**：得益于 Astro 的孤岛架构（Islands Architecture），零 JS 负担，页面秒开。
- 🎨 **现代化 UI**：采用深色主题、玻璃拟态（Glassmorphism）和流畅的 CSS 动效。
- 🔄 **平滑过渡**：全站启用 View Transitions，实现类似 SPA 的无缝跳转体验。
- 🏷️ **内容管理**：支持标签云、分类云、文章归档，使用 Markdown/MDX 编写内容。
- 💬 **互动交流**：集成了 Twikoo 评论系统，方便读者交流。
- 🔍 **全局搜索**：集成了 Pagefind 静态搜索。

## 文档结构

- **更新日志 (Changelog)**：记录了项目从早期版本到现在的迭代过程。
- **问题记录 (Issues)**：记录了开发过程中遇到的各种技术难题及其解决方案（例如 Astro ViewTransitions 导致的 JS 失效问题）。

## 技术栈

- [Astro](https://astro.build/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Twikoo](https://twikoo.js.org/) (评论系统)
- [Pagefind](https://pagefind.app/) (搜索)
